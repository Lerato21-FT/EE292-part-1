The tests that pay for themselves, and the scope no test covers:

The tests that pay for themselves are the fast numerical unit tests for the fitting formulas and unit conversions, the API validation tests for uploads/exclusions, and the Chromium browser check for linked exclusions, recovery, responsive layouts, and PNG export. They catch regressions without requiring manual analysis of every plot.

The automated tests do not cover every possible real-world CSV dataset or measurement condition. They mainly cover the bundled demo data and controlled synthetic datasets.
