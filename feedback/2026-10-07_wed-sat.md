## Wed 2026-10-07

- `3fee3a2` Initial commit: Add project files.
- **Goal (`PROMPT.md`):** a local-only FastAPI web app for field-swept FMR
  sweeps on magnetic-insulator thin films. The sweeps were measured with
  lock-in detection, with frequency in the filename, field (Oe) in column 1
  and the lock-in signal in column 2. The app plots frequency vs resonance
  field with an in-plane Kittel fit (uniaxial out-of-plane anisotropy,
  four-fold in-plane anisotropy, Landé g), and linewidth vs frequency with a
  damping fit. The fitted equations appear on the plots.
- **Standards:** `AGENTS.md` (no host installs, Makefile-only commands,
  feature branches, result computed in the backend, localhost-only),
  `ARCHITECTURE.md`, `README.md`, `.env.example`, `CLAUDE.md`.
- **Backend:** `src/app/api.py`, `dataset_store.py`, `models.py` and
  `pipeline.py` (derivative-Lorentzian resonance fits, Kittel fit,
  linewidth/damping fit).
- **Frontend:** `src/web/` with HTML, CSS and Plotly-based `app.js`.
- **Data:** 50 bundled in-plane sweeps in `broadband_100/` (5–29 GHz).
- **Build:** `docker/` (Dockerfile, compose, uv/npm lockfiles) and a Makefile
  with `build`, `up`, `down`, `test`, `lint`, `fmt`, `smoke` and
  `verify = lint + test + smoke`.
- **Tests:** `tests/test_api.py`, `test_dataset_store.py`, `test_pipeline.py`.
- **Issues introduced:** a `.DS_Store` file was committed, and so was
  `ee292m.env`, which holds a course API key. The key file was removed later
  (see 2026-10-14), but it remains in git history.
