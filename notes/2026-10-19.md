# 2026-10-19 — Perpendicular FMR analysis and responsive plots

## Implemented behavior

- Added In-plane / Out-of-plane geometry selection. Changing geometry hides
  stale results and requests a matching CSV folder. The in-plane demo remains
  the startup dataset; one validated upload replaces it at a time.
- Upload validation runs the selected model before activating files,
  geometry and initialization together. Failed uploads retain the previous
  dataset and settings. Reloading the browser restores the active geometry.
  Analysis responses include the starting field and linewidth so reloaded
  controls can display the accepted initialization accurately.
- Added saturated perpendicular Kittel fitting and reused the derivative
  Lorentzian and linewidth/damping pipeline. The API returns geometry and
  a nullable four-fold term; the perpendicular view displays N/A for that term.
- Added editable initial perpendicular field and peak-to-peak linewidth.
  The backend computes resonance fields, linewidths, fits, conversions and
  damping. The frontend handles drawing, labels and interactions only.
- Improved chart heights, axis titles, margins, equation/legend placement,
  responsive resizing, wrapped captions, and keyboard focus visibility.
  Plots become a single column below 1100 px. PNG exports include fitted
  values and an opaque dark background at 2000 × 1400 pixels.

## Scientific conventions approved for this implementation

```text
Beff,⊥ = μ0 Ms − μ0 H2⊥
f = (g μB/h)(Bres − Beff,⊥)
ΔHpp = 2Γ/√3
ΔHpp(f) = ΔHpp,0 + (4πα/√3γ) f
γ = g μB/ħ
```

The −0.4 T value initializes the effective perpendicular field, including
demagnetization; it is not intrinsic anisotropy or Ku. The 10 Oe value
initializes derivative peak-to-peak linewidth, not absorption FWHM.
Negative Beff,⊥ means perpendicular anisotropy exceeds demagnetization.
The model assumes saturated, field-aligned magnetization on the nonnegative
applied-field branch with Bres − Beff,⊥ > 0. No four-fold term is identifiable
from perpendicular dispersion. An independent saturation magnetization is
needed to recover intrinsic anisotropy.

The perpendicular fit bounds g to 1–4 and Beff,⊥ to −2–2 T, additionally
constraining Beff,⊥ below the smallest resonance field. At least four finite
resonance points and distinct fields are required. In-plane fitting retains
the aligned-axis model, 0.9 T initialization and adaptive linewidth seed.

Reference: [Gopman et al., Ferromagnetic resonance measurements of
(Co/Ni/Co/Pt) multilayers with perpendicular magnetic anisotropy](https://pmc.ncbi.nlm.nih.gov/articles/PMC7580010/).

## Build and validation support

- Added `make browser` with a separately built Chromium/Playwright image.
  Playwright is pinned in an optional dependency group in the Python lock;
  the browser and its system libraries are installed during image building.
  The normal app image excludes that group and the browser binaries.
- `make verify` includes browser checks. The browser workflow uses an
  isolated API inside its container and writes screenshots/PNGs only to
  gitignored repository `artifacts/`.
- Added `make review` for whitespace/status checks and `FORMAT_PATHS` for
  targeted formatting. Docker builder metadata now stays in gitignored
  `.cache/buildx/` inside the repository.
- No host dependencies or new application runtime dependencies were added.

## Limits

No measured out-of-plane dataset was supplied; perpendicular numerical and
browser workflows use synthetic sweeps. The bundled measured dataset covers
in-plane regression checks. This implementation does not establish sample
saturation, estimate parameter uncertainties, model tilted/domain states,
or independently determine intrinsic Ku. Browser automation targets Chromium;
other browser engines require separate checks.
